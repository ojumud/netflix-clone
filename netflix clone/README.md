# Streamly — Netflix Landing Page Clone

A front-end recreation of Netflix's browsing UI, built to practice layout, responsive design, and vanilla JavaScript DOM manipulation. Fan-made, for learning purposes only — not affiliated with Netflix.

## Features
- Fixed navbar that changes background on scroll
- Full-bleed hero section with gradient overlay and CTA buttons
- Horizontally scrollable content rows with hover-to-zoom cards
- Left/right arrow navigation per row
- Mobile-responsive layout with a collapsible menu

## Tech Stack
- HTML5
- CSS3 (Flexbox, custom properties, media queries)
- Vanilla JavaScript (no frameworks)

## Getting Started
1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/streamly-netflix-clone.git
   ```
2. Open `index.html` in your browser — no build step required.
